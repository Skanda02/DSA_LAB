a. Declare a calender as an array of 7 elements(A dynamically Created array) to represent 7 days of a week. Each Element of the array is a structure haveing three fields<br>
- The first field is the name of the Day(A dynamically allocated String)<br>
- The second field is the date of the Day(A integer)<br>
